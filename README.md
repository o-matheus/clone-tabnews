# Estudos do curso.dev

Este projeto acompanha meu estudo no [curso.dev](https://curso.dev), com o código das atividades e anotações organizadas por dia do curso.

## Anotações

Consulte o [índice de anotações](anotacoes/README.md) para acompanhar o progresso ou use o [modelo](anotacoes/modelo.md) para registrar um novo dia.

Cada arquivo, como `dia-001.md`, corresponde ao número do dia no curso. A data dentro do arquivo indica quando estudei; um dia do curso pode ser estudado em mais de uma data.

## Como estudar neste projeto

1. Assista às aulas e desenvolva as atividades conforme o curso avançar.
2. Registre os conceitos, a prática e as dúvidas no arquivo do dia correspondente.
3. Peça ajuda quando precisar: o padrão é receber explicações e dicas primeiro, com a solução completa quando solicitada.
4. Atualize o status no arquivo do dia e no índice ao iniciar ou concluir o conteúdo.

As orientações para os assistentes estão em [AGENTS.md](AGENTS.md). As anotações preservam o progresso e as dúvidas para retomar o estudo em outra conversa ou ferramenta.
