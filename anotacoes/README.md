# Anotações por dia

O número do arquivo corresponde ao dia do curso. As datas de estudo ficam dentro de cada anotação.

## Progresso

| Dia do curso | Status | Anotações |
| --- | --- | --- |
| 001 | concluído | [Dia 001](dia-001.md) |
| 002 | concluído | [Dia 002](dia-002.md) |
| 003 | concluído | [Dia 003](dia-003.md) |

Status disponíveis: **não iniciado**, **em andamento** e **concluído**.

## Registrar um novo dia

1. Copie o [modelo](modelo.md) para `dia-NNN.md`, substituindo `NNN` pelo número do dia com pelo menos três dígitos, como `002`.
2. Ajuste o título para o dia correspondente e preencha o conteúdo conforme estudar.
3. Adicione uma linha ao índice e mantenha o status igual ao registrado no arquivo do dia.
